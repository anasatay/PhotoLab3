# Лабораторная работа №3 — простой фоторедактор на C#

## Назначение
Учебная консольная программа для просмотра и редактирования фотографий. Графический интерфейс не требуется. Программа рассчитана на **Windows, .NET 9, Visual Studio 2022** (System.Drawing.Common для Windows).

## Как открыть
1. Распаковать архив в папку.
2. В Visual Studio 2022 открыть `PhotoLab3_Simple.sln` через «Открыть проект или решение».
3. Дождаться восстановления NuGet-пакетов (нужен интернет при первом восстановлении).
4. Правой кнопкой на проект `PhotoLab3` → «Назначить запускаемым проектом».
5. Нажать `Ctrl+F5`.
6. Выбрать команду `1`, ввести полный путь к JPG/PNG, затем выполнять команды меню.

## Меню
- `1` — загрузить фото;
- `2` — список;
- `3` — выбрать фото;
- `4` — открыть текущее фото в стандартном просмотрщике Windows;
- `5` — обрезка;
- `6` — поворот на 90, 180, 270 градусов;
- `7` — изменить яркость;
- `8` — чёрно-белый фильтр;
- `9` — негатив;
- `10` — изменить пиксель;
- `11` — добавить надпись;
- `12` — коллаж из двух фотографий (горизонтальное объединение);
- `13` — экспорт PNG;
- `14` — сохранить проект;
- `0` — сохранить проект и выйти.

После фильтров и других операций выбрать `4` для просмотра результата. Фото на диске, которое загружали, не изменяется.

## Где сохраняется проект
`Документы/PhotoLab3Saved/project.json` содержит сведения о фото и индекс выбранной фотографии. В `Документы/PhotoLab3Saved/Images` хранятся отредактированные изображения PNG. При следующем запуске программа загружает их автоматически. JSON — сериализация объектов; чтение JSON — десериализация.

Важно: не удаляйте папку `Images`, иначе загрузка проекта не удастся. Нельзя обрезать за пределами изображения. Большие фотографии фильтруются медленнее из-за простых циклов GetPixel/SetPixel — это учебная реализация.

## Какие файлы за что отвечают
- `Photo.cs`: свойства фотографии, включая `[JsonIgnore]` у Bitmap.
- `IPhotoEditor.cs`: интерфейс с доступными операциями.
- `PhotoEditor.cs`: конкретная реализация редактора, циклы и Graphics.
- `PhotoStorage.cs`: запись и чтение JSON + PNG.
- `Program.cs`: меню и взаимодействие с пользователем.
- `PhotoEditorTests.cs`: 9 тестов xUnit.

## Как запустить тесты
В меню Visual Studio открыть **Тест → Обозреватель тестов**, затем **Запустить все тесты**. Они проверяют обрезку, поворот, изменение пикселей, фильтры, коллаж, сохранение и восстановление.

## Git
1. Visual Studio → **Git → Создать репозиторий Git** (локальный).
2. В **Изменения Git** выбрать все файлы и выполнить первый коммит: `Первая версия фоторедактора`.
3. Если преподаватель требует удалённое хранение, опубликовать репозиторий на GitHub из Visual Studio.

В архиве находятся исходники, но **история коммитов и удалённый Git-репозиторий не создаются автоматически**.

## Как устроена работа (для защиты)
1. `Program` спрашивает команду и передает изображение редактору через `IPhotoEditor`.
2. `PhotoEditor` изменяет изображение (обрезает, поворачивает, применяет фильтры и т.д.).
3. `Photo` хранит имя, имя файла и `Bitmap`.
4. `PhotoStorage` сохраняет состояние в JSON и картинки в PNG.
5. После выхода команда `0` сохраняет всё. При новом запуске данные восстанавливаются.
6. Тесты автоматически сравнивают ожидаемые и полученные результаты отдельных методов.

## Ограничения учебной версии
- Работает только в Windows.
- Нет собственной графической формы: просмотр происходит через стандартное приложение Windows.
- Коллаж из двух снимков расположен горизонтально.
- Для простоты нет отмены действий, истории изменений и режима перетаскивания.
- Сохранение рассчитано на обычное корректное завершение команды `0` (при принудительном закрытии сохраняется последняя версия, записанная командой `14` или `0`).
