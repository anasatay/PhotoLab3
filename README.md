
# Лабораторная работа №3. Фоторедактор

**Дисциплина:** Программирование  
**Вариант:** 1  
**Язык программирования:** C#  
**Среда разработки:** Visual Studio 2022  
**Платформа:** .NET 9, Windows

## Описание проекта

Разработано консольное приложение для просмотра и обработки цифровых фотографий. Программа позволяет загружать изображения, выполнять основные операции редактирования и сохранять полученные результаты.

Приложение реализовано с использованием объектно-ориентированного подхода. Функции обработки изображений, хранения данных и управления программой разделены между отдельными классами.

## Функциональные возможности

- Загрузка и просмотр фотографий в форматах JPG и PNG.
- Выбор изображения из списка загруженных фотографий.
- Обрезка по заданным координатам и размерам.
- Поворот на 90°, 180° и 270°.
- Увеличение и уменьшение яркости.
- Преобразование изображения в оттенки серого.
- Создание негатива.
- Изменение цвета отдельного пикселя по координатам.
- Добавление текстовых надписей.
- Создание коллажа из двух фотографий.
- Сохранение обработанного изображения в PNG.
- Сохранение и восстановление состояния программы.

## Структура проекта

| Файл | Назначение |
|---|---|
| `Program.cs` | Консольное меню и обработка команд |
| `Photo.cs` | Хранение информации о фотографии |
| `IPhotoEditor.cs` | Интерфейс операций обработки |
| `PhotoEditor.cs` | Реализация методов редактирования |
| `PhotoStorage.cs` | Сохранение и загрузка проекта |
| `PhotoEditorTests.cs` | Модульные тесты |

## Сохранение состояния

Для сохранения данных используется сериализация в формат JSON с помощью библиотеки `System.Text.Json`.

Состояние проекта сохраняется в папке `Документы\PhotoLab3Saved`:

- **`project.json`** — информация о фотографиях и индекс выбранного изображения.
- **`Images`** — папка с обработанными фотографиями в формате PNG.

При следующем запуске приложение автоматически загружает сохранённый проект и восстанавливает результаты редактирования.

## Модульное тестирование

Тестирование реализовано с использованием **xUnit**.

Проект `PhotoLab3.Tests` содержит **16 модульных тестов**, которые проверяют:

- Обрезку и поворот фотографий.
- Изменение цвета пикселей.
- Работу фильтров яркости, оттенков серого и негатива.
- Создание коллажей и добавление надписей.
- Обработку некорректных параметров.
- Сохранение и восстановление данных.

Тестами охвачены основные методы классов `PhotoEditor` и `PhotoStorage`.
