Лабораторная работа №3

Просмотрщик фотографий с возможностью обработки

Дисциплина: Программирование
Вариант: 1
Язык программирования: C#
Платформа: .NET 9, Windows
Тип приложения: консольное

Назначение программы

Разработано консольное приложение для просмотра и обработки цифровых фотографий. Программа позволяет загружать изображения, выполнять основные операции редактирования и сохранять полученные результаты.

Приложение реализовано с использованием объектно-ориентированного подхода. Функции обработки изображений, хранения данных и управления программой разделены между отдельными классами.

Функциональные возможности

В программе реализованы следующие операции:

Загрузка и просмотр изображений форматов JPG и PNG.

Выбор фотографии из списка загруженных изображений.

Обрезка по заданным координатам и размерам.

Поворот на 90°, 180° и 270°.

Увеличение и уменьшение яркости.

Преобразование изображения в оттенки серого.

Создание негатива.

Изменение цвета отдельного пикселя по координатам RGB.

Добавление текстовой надписи.

Создание горизонтального коллажа из двух фотографий.

Экспорт обработанного изображения в PNG.

Сохранение и восстановление состояния проекта.

Управление осуществляется через консольное меню. Для просмотра фотографий используется приложение Windows, назначенное для открытия графических файлов.

Сохранение состояния

Сохранение проекта реализовано с использованием сериализации и десериализации JSON.

В каталоге Документы\PhotoLab3Saved создаются:

project.json — информация о фотографиях и индекс выбранного изображения;

Images — каталог с обработанными фотографиями в формате PNG.

При повторном запуске приложения сохранённые данные загружаются автоматически. Это позволяет восстановить список фотографий, результаты редактирования и выбранное изображение.

Модульное тестирование

Для проверки программы используется библиотека xUnit.

В проекте PhotoLab3.Tests реализовано 16 модульных тестов, проверяющих:

правильность обрезки и поворота изображений;

изменение цветов пикселей;

работу фильтров яркости, негатива и оттенков серого;

добавление надписей и создание коллажей;

обработку недопустимых параметров;

сохранение и восстановление проекта.

Тесты проверяют основные методы классов PhotoEditor и PhotoStorage.
